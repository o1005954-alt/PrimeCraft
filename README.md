# PrimeCraft 2.0

A fast, dockable toolkit panel for **EffectCraft**.

PrimeCraft puts the tools you use all day into one compact panel: layer setup, keyframe easing, expressions, timing, and effects—all one click away. It features **86 tools across four tabs** where every action is a single Undo step, eliminating the need to dig through menus or deal with popup alerts.

---

## Features

### Layers
* **Quick Creation:** Create solids, adjustment layers, nulls, text, cameras, and lights directly above your selection.
* **Alignment & Scaling:** Center position or anchor point without moving the layer; Fit, Fill, or Stretch to Comp.
* **Layer Organization:** Pre-compose, parent to a new null, reverse stacking order, batch rename, stagger, and sequence.

### Motion
* **Keyframe Easing:** Easy Ease, Ease In, Ease Out, Linear, and Hold with adjustable ease influence.
* **One-Click Expressions:** Instantly apply Wiggle, Spin, Loop, Ping-Pong, and Bounce.
* **Animation Presets:** Fade In/Out, Pop In, and Slide In from any edge.

### Time
* **Layer Timing:** Split, trim, move layers to the current time, and extend layers to the comp length.
* **Playback & Speed:** Freeze Frame, Hold from CTI, Reverse Layer, and Speed %.
* **Comp & Export:** Set the work area, trim the comp to its layers, add markers, export a still frame as PNG, and add the comp to the Render Queue.

### FX
* **30 One-Click Effects:** Covers blur, color, stylize, and distort categories.
* **Flexible Application:** Apply effects directly to selected layers or to a new adjustment layer with a single toggle.
* **Batch Control:** Toggle all effects on or off, or clear all effects from selected layers.

---

## Built for Speed
* **Instant Search:** Find any tool by name.
* **Repeat Last Action:** Re-run your previous operation in a single click.
* **Non-Blocking Feedback:** Status bar with hover tooltips and clean inline notifications.
* **Session Persistence:** Remembers your active tab, ease strength, and dialog values between sessions.
* **Full Compatibility:** Works with keyframed properties, separated position dimensions, and non-English versions of EffectCraft.

---

## Installation

1. Copy `PrimeCraft.jsx` into your EffectCraft `Scripts/ScriptUI Panels/` folder.
2. Restart **EffectCraft**.
3. Open the panel from **Window > PrimeCraft.jsx** (or run it as a floating window via **File > Scripts > Run Script File**).
